# Lumen — онлайн-библиотека

Пастельный frontend-прототип библиотеки по ТЗ. Сейчас интерфейс работает на мок-данных, поэтому его можно открыть без backend.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Тестовые аккаунты

- Студент: `student@lumen.ru` / `lumen`
- Администратор: `admin@lumen.ru` / `lumen`

## Что реализовано

- главная страница и единый адаптивный стиль;
- каталог с поиском, фильтрами и сортировкой;
- публичная страница книги по QR-коду в формате `/books/:id`;
- вход, хранение сессии в `localStorage`, logout и защита зон;
- кабинет студента: книги на руках, сроки, штрафы и история;
- демонстрационный reader с прогрессом чтения;
- админ-панель: книги, категории, студенты, выдача и возврат;
- пустые состояния, уведомления и адаптивная мобильная версия.

## Подключение API

Замените мок-данные в `src/main.js` на слой запросов с базовым URL из `VITE_API_URL`. Расчёт штрафов и проверка доступности должны оставаться на backend. В `.env` можно добавить `VITE_USE_MOCKS=false`.
